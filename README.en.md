A Chromium-based browser extension that removes clutter from Allegro.pl pages: ads, recommendation carousels, promotional banners and other distractions. Every element can be turned on or off individually in the extension popup.

Hidden elements cover the main parts of the site, including category and search listings, product pages (also for ended offers), offer comparison, favorites, cart, order confirmation, purchase history and other pages.

It also adds several useful features, such as changing the default sorting, expanding descriptions, and disabling the image-swapping effect that occurs when hovering over thumbnails.

In total, there are 60 elements that can be hidden, along with a few additional features.

## Installation (offline, unpacked)
1. [Download the latest ZIP](https://github.com/xeophyte/Allegro-Clean-View-mod/releases/latest/download/Allegro.Clean.View.mod.zip) and extract it ("Allegro Clean View (mod)" folder) to the permanent storage location of the plugin folder.
2. Open the extensions page in your browser:
   - Chrome / Chromium: `chrome://extensions`
   - Edge: `edge://extensions`
   - Vivaldi: `vivaldi://extensions`
3. Turn on **Developer mode** (usually a toggle in the top-right corner).
4. Click **Load unpacked** and select the extracted "Allegro Clean View (mod)" folder.

**Notes**
- Do not delete, move or change name of the extracted folder, because the browser loads the extension directly from it.
- To update, download the new ZIP, replace the files in the same folder and click the reload button on the extension's card in the extensions page.
